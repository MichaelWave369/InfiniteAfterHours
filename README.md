# Infinite After Hours

**The screen sleeps. The worlds wake up.**

An original, local-first living screensaver and idle-story universe.

- **Infinite IdleKit:** reusable privacy-respecting idle runtime and event scheduler.
- **Infinite Island:** nine districts and an archived catalog of 100 story seeds.
- **Connected worlds:** Infinite Porch, Nested Bubble Observatory, More Bounce Radio, Silicon Louvre, and future original worlds.

Project in active development. The first implementation is proposed by pull request rather than committed directly to `main`.

## Provenance

The project builds upon privately preserved July 5, 2026 concept packets for *Parallax IdleKit*, *Parallax Island 100 Idle Adventures*, and the *Idle Event Rotation System*. These earlier names describe historical design work, not the public branding or third-party dependencies of this repo. Original archive files remain untouched.

Inspired by the **concept** of story-driven screensavers, not their proprietary code, characters, art, or branding.

## Principles

Original art and code · offline-first · local event history · no raw private documents on idle screens · reduced motion and instant return · no false status claims.
