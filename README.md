# Infinite After Hours

**The screen sleeps. The worlds wake up.**

A free and original story-driven screensaver *preview*: Infinite Island, Infinite Porch, Nested Bubble Observatory, More Bounce Radio, and Silicon Louvre. Powered by Infinite IdleKit.

## v0.1 scope

A React/Vite preview, nine-district map, twelve short story cards, a local-first weighted event scheduler, a mock build-signal panel, manual saver preview, reduced-motion controls, and basic tests. These are **story-card previews**, not twelve fully animated films. The historic 100-episode packet is a design archive, not a claim that 100 cartoons have shipped.

Run: npm install, npm run dev. Checks: npm test, npm run build.

## GitHub Pages

The workflow verifies pull requests, builds on main, and can deploy to GitHub Pages after setting **Settings > Pages > Source: GitHub Actions**. Target URL: https://michaelwave369.github.io/InfiniteAfterHours/

## Provenance

The project develops the owner's July 5, 2026 design packets: *Parallax IdleKit Master Spec*, *Parallax Island 100 Idle Adventures*, and *Island Idle Event Rotation System*. The archive files remain unchanged. Historical terminology is not shipped branding. This repo does not use proprietary Johnny Castaway, Sierra or After Dark characters, artwork, code or media.

## Guardrails

Original art and code, no tracking, no raw documents or private filenames on idle screens, allowlisted simulated app statuses only, local history, silent by default, reduced motion, immediate return to work. The NBG artwork is a visual metaphor, **not scientific validation**.

This is a web preview, **not** a Windows system-installed .scr. Native screensaver integration requires a separate, security-tested Windows host that respects the OS lock screen.
